# TESLAQTOBE AI GEO-ROUTE

Ғылыми жоба: **Никола Тесланың жаңартылатын энергия идеялары мен жасанды интеллект негізінде Ақтөбе облысының ақылды туристік маршрутын әзірлеу**

Ақтөбе облысының үш өлшемді интерактивті картасы: туристік нысандар, Tesla Smart Station желісі, электромобильмен жүру, үш маршрутты салыстыру, AI зертхана (Дейкстра алгоритмі), ауа райы симуляторы және қазақша дауыстық сүйемелдеу.

## Авторлар

- Орындаған: Тұрғанбаева Айсана Саматқызы, Қуандық Нұрислам Сәкенұлы (10-сынып)
- Мектебі: «Қаражар орта мектебі» КММ
- Ғылыми жетекші: Жұбаналина Нұрия Шоқанқызы

## Іске қосу

`index.html` файлын браузерде (Chrome ұсынылады) ашыңыз. Орнатуды қажет етпейді, интернетсіз жұмыс істейді.

## Құрылымы

- `index.html`, `app.css`, `app.js` — сайт
- `lib/` — three.js (MIT лицензиясы)
- `audio/` — қазақша дауыстық сүйемелдеу (синтезделген дауыс)
- `img/` — фотосуреттер
